# goodbean-roastery
“Vector เริ่มต้นจากร้าน Pop-up เล็ก ๆ ในมหาวิทยาลัยขอนแก่น ก่อนที่เจ้าของจะสั่งสมประสบการณ์ด้านกาแฟและพัฒนาต่อยอดจนกลายเป็น Vector Coffee Roaster ในตัวเมืองขอนแก่น จุดเด่นของแบรนด์คือการให้ความสำคัญกับคุณภาพกาแฟ และพร้อมปรับตัวตามความต้องการของลูกค้า โดยยังคงเอกลักษณ์ของตัวเองไว้”
